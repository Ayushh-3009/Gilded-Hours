## ✨ Features

- **🔒 User Authentication**: Sign in, create accounts, and keep all personal data securely isolated per user in local storage.
- **📋 Smart To-Do Lists**: Manage tasks with priorities (High, Medium, Low), tags, due dates, subtasks, and quick filters (Today, Upcoming, All, Completed).
- **🕐 Time Blocking Timeline**: Daily visual timeline (30-min slots) with live time indicator line, category color-coding, and drag-and-drop scheduling.
- **🔥 Habit Tracker & Heatmap**: Daily/weekly habits with streak counters, completion percentages, and a 12-week GitHub-style activity heatmap.
- **🔄 Step-by-Step Routines**: Build morning, evening, or custom routines with durations and run them interactively as a live checklist.
- **📝 Daily Journal**: Reflect with mood tracking, gratitude notes, thoughtful writing prompts, calendar history, and search.
- **🔔 Reminders & Audio Chimes**: Set scheduled reminders with cozy Web Audio chime alerts, toast notifications, snooze (+10m), and repeat intervals.
- **📜 Past Activity Stream**: Continuous, authentic audit trail of all completed milestones with category filtering and JSON export.
- **👤 Custom Profiles & Avatars**: Upload personal photos, paste web image URLs, pick cozy preset emojis, or enter custom initials, plus 6 cozy ambient theme accents.

## 🚀 Instant Deployment on Vercel

### Deploy via GitHub

1. Push this repository to your **GitHub** account.
2. Go to [vercel.com](https://vercel.com) and sign in.
3. Click **"Add New..."** ➔ **"Project"**.
4. Import your `gilded-hours` repository.
5. In **Build & Development Settings**, leave everything default (it's a static site).
6. Click **Deploy**!

Your app will be live with an automatic HTTPS URL (e.g. `https://gilded-hours.vercel.app`) and will automatically redeploy whenever you push commits to GitHub.

## 💻 Local Development

Run locally using Python's built-in server:

```bash
python -m http.server 3000
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
